# Wireless and Mobile Network (IT Department)

Welcome to the official repository for the **Wireless and Mobile Network** course at the University of Kirkuk, hosted by Dr.-Ing. Dalya Raad Al-Ani. This portal organizes weekly theoretical lectures (Weeks 1 through 15) and practical lab work using simulation tools like NS-3 and Mininet-WiFi.

## 📑 Course Syllabus Overview
The repository is structured with pre-configured markdown links for weekly lectures ranging from fundamentals and cellular evolution to 5G/6G, MAC layers, mobility management, and mobile edge computing. You can find the full weekly schedule and detailed markdown template inside the referenced documents.

## 🛠️ Required Technical Setup & Simulation Engines
* **NS-3 (Network Simulator 3)**
* **Mininet-WiFi Topology Emulator**

## 📚 Core References
Includes foundational texts by P. L. Dordal, K.-L. Du & M. N. S. Swamy, A. F. Molisch, L. Peterson & O. Sunay, and A. S. Tanenbaum & D. J. Wetherall.
